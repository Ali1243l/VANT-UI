# خطة التحديث الشامل: شعار ڤانت الحركي، إدارة الكتالوج الكاملة للأدمن، وإيماءات اللمس الاحترافية

خطة هندسية متكاملة تجمع بين تحسين الهوية البصرية الحركية، تنسيق الأسعار والعملة، توفير نظام إدارة كتالوج وعروض متكامل داخل لوحة الأدمن، وتطبيق إيماءات السحب باللمس للهواتف الذكية بسلاسة وأداء فائق.

---

## User Review & Critical Decisions

> [!IMPORTANT] 
> **القرارات المعتمدة وفق تفضيلاتك:**
> 1. **حركة الشعار**: حركة انسيابية تلقائية تتبدل بسلاسة بين "ڤانت" بالعربي و "VANT" بالإنجليزي كل 3.5 ثوانٍ مع تلاشي وحركة صعود خفيفة.
> 2. **تنسيق الأسعار والعملة**: السعر يُعرض بأرقام إنجليزية واضحة (مثل `95,000`) متبوعة برمز العملة (`د.ع` أو `IQD`) مع إمكانية التبديل والتحكم الكامل من لوحة الإدارة.
> 3. **إدارة المنتجات الكاملة في لوحة الأدمن**: واجهة متكاملة لإضافة قطع/عروض جديدة، تعديل الأسعار والتفاصيل والصور، وحذف أو إخفاء أي قطعة مع حفظ دائم وتصدير JSON للباك إند.
> 4. **إيماءات الموبايل**: سحب النافذة لأسفل لإغلاقها (`Swipe Down to Dismiss`) وتمرير الصور أفقياً باللمس (`Touch Carousel`) بدون أي تقطيع أو لاق.

## 1. Overview & Core Concept

- **الهوية والشعار الحركي**: تحويل شعار الهيدر إلى تبادل انسيابي بين الاسم العربي النقي "ڤانت" والاسم الإنجليزي "VANT" فقط (بدون دمج نصي)، مع ميزة النقر اليدوي للتبديل الفوري.
- **تنسيق العملة والأسعار**: توحيد صياغة الأسعار بالأرقام القياسية مثل `95,000 د.ع` أو `95,000 IQD` في كروت المنتجات ونافذة التفاصيل وتلخيص السعر.
- **نظام إدارة الكتالوج والعروض (Catalog & Offers CMS)**: قسم مخصص في لوحة الأدمن لإدارة كل قطعة:
  - إضافة منتج جديد (الاسم بالعربي والانكليزي، السعر، التصنيف، رابط الصورة، التوفر، الوصف، المقاسات، والوسوم).
  - تعديل فوري لأي قطعة موجودة (تغيير السعر، تحديث رابط الصورة، تعديل التوفر).
  - حذف القطع أو إلغاء العروض بنقرة واحدة.
  - استعادة الكتالوج الافتراضي أو استيراد وتصدير بيانات المنتجات كـ JSON.
- **تجربة اللمس وإيماءات الموبايل (Touch & Gestures)**:
  - إغلاق نافذة تفاصيل المنتج ونافذة الأدمن بالسحب لأسفل بسلاسة عبر مقبض السحب (Swipe Handle).
  - معرض صور تفاعلي للقطعة يدعم السحب الأفقي باللمس (Swipe Carousel) مع مؤشرات النقاط ومعدل إطارات 60fps بدون أي لاق.

## 2. User Experience & Visual Design

### رحلة المستخدم والتفاعل:
1. **الهيدر والشعار**:
   - يشاهد الزائر في منتصف الهيدر الشعار الأنيق يتبدل بانسيابية وتلاشٍ فاخر بين `ڤانت` و `VANT`.
2. **شبكة المنتجات والأسعار**:
   - كل كرت يعرض السعر بصيغة واضحة مثل `95,000 د.ع`.
3. **نافذة تفاصيل القطعة بالموبايل**:
   - إمكانية سحب الصور باللمس (يمين ويسار) للتنقل بين الصور المتاحة.
   - سحب النافذة نفسها لأسفل لإغلاقها فورياً بدون الحاجة للضغط على زر الإغلاق.
4. **لوحة الإدارة المتطورة**:
   - تبويبان رئيسيان: **إدارة المنتجات والعروض** و **التحكم بالأزرار والعملة**.
   - نموذج إضافة وتعديل سهل وسريع مع معاينة مباشرة للصورة والبيانات.

## 4. خطة التنفيذ المباشرة بعد الموافقة

1. **تحديث الشعار الحركي (`Header.tsx`)**:
   - تفعيل تبديل دوري سلس كل 3.5 ثوانٍ بين `ڤانت` و `VANT`.
   - استخدام تأثير `AnimatePresence` لتلاشي وحركة عمودية رقيقة.

2. **تحديث سياق ومكونات التحكم بالعملة والأسعار (`SiteControlsContext.tsx` & `ProductCard.tsx` & `ProductDrawer.tsx`)**:
   - دمج خيار العملة في الإعدادات (`IQD` أو `د.ع`).
   - دالة تنسيق أسعار قياسية بالأرقام الإنجليزية والفاصلة الآلاف (`95,000 د.ع`).

3. **بناء نظام إدارة المنتجات في سياق البيانات ولوحة الأدمن (`SiteControlsContext.tsx` & `AdminDrawer.tsx`)**:
   - دعم حفظ وتعديل وإضافة وحذف المنتجات محلياً مع المزامنة الفورية.
   - بناء واجهة إضافة وتعديل احترافية مع حقول لإدخال الصور، السعر، والوصف.

4. **تطوير إيماءات السحب واللمس للهواتف (`ProductDrawer.tsx`)**:
   - تفعيل إيماءة السحب للأسفل للإغلاق عبر Framer Motion `drag="y"`.
   - إضافة معرض صور أفقي متجاوب باللمس مع دعم السحب والانتقال السلس بين الصور.
